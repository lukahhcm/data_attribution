\section{Experimental Design}
\label{sec:experiments}

\subsection{Correctness gates}

Before the main matrix, a low-dimensional strongly convex problem verifies all
three rows of Table~\ref{tab:attribution-correspondence}. For the equilibrium
objective, analytic and finite-difference hypergradients are compared with the
implicit-differentiation expression in Eq.~(\ref{eq:if-hypergradient}) and the
concatenated Influence Function scores. For a fixed $T$-step objective, full
autodifferentiation is compared with the recurrence in
Eq.~(\ref{eq:gu-recurrence}) and the summed TSLOO scores in
Eq.~(\ref{eq:tsloo-gu-correspondence}). For the value-function objective, direct
outer autodifferentiation is compared with
Eq.~(\ref{eq:loss-difference-gradient}). Within each matched target, the sign
must agree and pairwise cosine similarity must exceed $0.99$. Projection tests require
$0\leq\omega_i\leq1$, $\sum_i\omega_i=B$, deterministic Top-$B$ tie breaking,
and exact recovery of $\vomega^{\mathrm{unif}}$. On MNIST with 10\% label
noise, we then hold $\vomega$ fixed and increase inner passes until both inner
residuals, score cosine, and Top-$B$ Jaccard similarity stabilize. Fixed inner
passes are used in the main matrix; an adaptive convergence rule is retained
only as the high-fidelity RQ1 reference.

\subsection{Fixed budget and common training contract}

The candidate set has $n$ examples and every real target epoch uses exactly
$B=0.1n$ unique examples. The selector maintains
\begin{equation}
\Wbudget=\{\vomega\in[0,1]^n:\textstyle\sum_i\omega_i=B\},
\qquad S_r=\operatorname{TopB}(\vomega_r).
\end{equation}
Here $\vomega$ is the continuous outer state, the score is its update
direction, and $S_r$ is used only to train the target. Every paired comparison
fixes the data split, noise realization, initialization, warm-start checkpoint,
target architecture, AdamW optimizer, scheduler, target epochs, and examples
per epoch. Development data select configurations; the test set is evaluated
once at each preregistered endpoint.

are later extensions rather than degrees of freedom in the primary result.

\subsection{One-shot controls from all three attribution families}

Before expanding the VF--RHO branch, we retain the two one-shot methods from
the unified analysis. \textbf{IF-1} computes Eq.~(\ref{eq:if-score}) with a
conjugate-gradient inverse-Hessian--vector product. \textbf{TSLOO-1} records a
fixed inner training trajectory and sums Eq.~(\ref{eq:tsloo-score}) over the
occurrences of each candidate; the exact recurrence is used on MNIST and the
preregistered checkpoint approximation is used on CIFAR. Each method selects
Top-$B$ once, then trains its target branch from the common warm-start
checkpoint to $H$ with the subset frozen. VF-Persistent-1 and RHO-Persistent-1
provide the corresponding one-shot controls for the third family.

The theoretical identities use the canonical all-present point
$\vomega=\bm{1}$. For the selection comparison we additionally report the
budget-uniform point $\vomega^{\mathrm{unif}}$ and never mix the two labels.
All methods use the same $f$, candidate data, and evaluation checkpoint within
a comparison. Auxiliary examples, Hessian-vector products, saved checkpoints,
and scoring time are reported so that a more expensive attribution evaluator
cannot appear compute-matched by construction.

\subsection{RQ1/RQ2: fixed-horizon block protocol}

After the common warm start, the target runs for five blocks. At the start of
each block, a method may execute one complete selection update. For
$R\in\{1,2,3,4,5\}$, the selector updates at the first $R$ boundaries, then
freezes its state and Top-$B$ subset while the target continues to the common
horizon $H$. We save a complete checkpoint after every block and branch each
freeze-$R$ continuation from the corresponding boundary. This construction
holds target epochs, target examples, optimizer, and scheduler fixed as the
number of bilevel rounds changes.

The $R=1$ branch is one-shot attribution-then-selection. One VF round updates
the two inner models under the preregistered pass count, evaluates the global
score, takes one projected outer step, and deploys Top-$B$ for the next block.
The strict reference maintains
\begin{align}
\thetahat(\vomega)&\leftarrow\argmin_{\vtheta}g(\vomega,\vtheta),\\
\thetatilde(\vomega)&\leftarrow\argmin_{\vtheta}
\{f(\vtheta)+\alpha_r g(\vomega,\vtheta)\},\\
s_i&=\ell(\thetahat;z_i)-\ell(\thetatilde;z_i),
\end{align}
with the fixed schedule $\alpha_r=\alpha_0(1+r)^p$. The same $\alpha_r$ enters
the penalized inner objective and its outer direction.

At every boundary we save the target, $\thetahat$, $\thetatilde$, all
optimizer and scheduler states, continuous $\vomega$, raw scores, Top-$B$
indices, BatchNorm buffers, random-number-generator states, and development
metrics. The key paired contrasts are Persistent-$R$ versus Persistent-1
(additional complete rounds), Reset-$R$ versus Reset-1 (rescoring alone), and
Persistent-$R$ versus Reset-$R$ (outer memory).

\subsection{RQ3: separating the RHO score from its protocol}

We add practical RHO mechanisms in a fixed order:
\begin{enumerate}
    \item \textbf{RHO-Global-TopB:} score all candidates at a block boundary,
    take global Top-$10\%$, and train for the block;
    \item \textbf{RHO-GlobalScore-LocalQuota:} keep that block-start score but
    take Top-$10\%$ separately within each candidate batch;
    \item \textbf{RHO-Stale-Online:} immediately update the target after each
    local selection while retaining the block-start scores; and
    \item \textbf{RHO-Batch-Faithful:} rescore every candidate batch with the
    latest target, take local Top-$10\%$, and update immediately.
\end{enumerate}
At the same protocol points, we substitute three score sources: strict VF;
current target plus an updating joint comparator; and current target plus the
frozen holdout IL model. The resulting grid separates error in the
loss-difference approximation from the diversity and adaptation effects of
the online training protocol.

and set the candidate batch to $n_B=10n_b$. Thus local retention remains 10\%:

The final incomplete candidate batch selects the rounded 10\% quota, followed
by an epoch-level exact-budget correction so that precisely $0.1n$ distinct
examples are trained on. Increasing $n_b$ holds target examples fixed but
reduces target optimizer steps; this is part of the intervention. We therefore
report progress against examples, optimizer steps, and wall-clock rather than
calling the sweep a pure diversity test.

Every point compares \textbf{RHO-Batch-Faithful} with
\textbf{Uniform-Batch-Matched}, which shares candidate order, local quota,
immediate-update timing, target batches, and step counts but replaces ranking
with uniform sampling. The frozen IL/reference model is always trained with
batch size 32, and all five online scales for a fixed dataset, seed, and split
load the same reference checkpoint.

\subsection{Execution waves, metrics, and decision rules}

A diagnostic pre-wave runs IF-1, TSLOO-1, VF-Persistent-1, and
RHO-Persistent-1 on MNIST and CIFAR-10, seed 1, to validate the three-family
one-shot comparison. Wave 1 then runs the priority RHO batch study on MNIST and
CIFAR-10 with 10\% noise, seed 1, all five batch scales, and both matched
methods. Wave 2 expands every point to seeds 1--3. Wave 3 checks representative
points on CIFAR-100 and the clean condition; only development results choose
those points. Wave 4 launches the VF--RHO block-protocol matrix for
$R=1,\ldots,5$.

Primary outcomes are final test accuracy and best development loss. Mechanism
metrics are selected-noise rate, class entropy, cumulative unique coverage,
adjacent-round turnover, and the trajectories of $\vomega$ and score rank.
Resource metrics are target examples and optimizer steps, scoring examples,
wall time, and peak GPU memory. Accuracy-versus-target-data and
accuracy-versus-total-compute are both mandatory whenever methods process
different auxiliary examples.

We interpret results under four preregistered boundaries. If Persistent-$R$
improves with $R$ and exceeds Reset-$R$, the evidence supports optimizing
weights beyond one local direction at uniform utility. If Reset-$R$ improves
but Persistent-$R$ does not, the gain is attributed to fresh scores rather than
outer memory. If batch-faithful RHO wins only for small $n_b$, the candidate
explanations are local quota, online adaptation, and optimizer-step
granularity---not automatically a more accurate VF approximation. Finally, no
configuration selected using test performance is eligible for a primary
claim.
